# القرارات والمبادئ الثابتة — دورك

سجلّ القرارات المعمارية والتشغيلية والتجارية التي أقرّها المستخدم. هذه قواعد مُلزِمة لكل جلسة قادمة.

---

## 1. قرارات تشغيلية / أمنية (حرجة — مُلزِمة)

### 1.1 النشر الآمن
- النشر **حصراً** إلى الخادم `31.220.111.228` المسار `/var/www/salon` ثم `pm2 restart salon`.
- **يُمنع منعاً باتاً لمس تطبيق MagicAI** أو أي خدمة أخرى على الخادم (PHP/Laravel + MySQL + nginx:443). فصل SNI يحمي المجالين.
- **خطوات النشر القياسية:** اعمل على فرع محلي → ابنِ واختبر محلياً → ادمج ff-only إلى main → ادفع origin + userrepo → ssh → `git pull` → `npx prisma migrate deploy` (عند وجود هجرة) → `npm run build` → `pm2 restart salon` **فقط**.
- `NEXT_PUBLIC_APP_URL` يُحقَن وقت البناء → بعد تغيير الرابط يلزم `npm run build` لا مجرد restart.

### 1.2 الخادم البعيد للـ student-bot (مشروع منفصل)
- لا علاقة له بدورك؛ يعيش على stboot (`72.61.110.187:/opt/student-bot`). لا تخلط بينهما.

## 2. قرارات المنتج

### 2.1 Zero-install (غير قابل للتفاوض)
- متصفّح فقط، بلا إجبار على تثبيت PWA. أي ميزة (حتى Push) لا تكسر هذا المبدأ.

### 2.2 العربية الافتراضية + تعدّد اللغات الشامل
- العربية هي اللغة الافتراضية (RTL).
- قرار المستخدم الصريح: **«الترجمة تغطي كل الصفحات بدون استثناء وتظهر في كل الشاشات على أن تكون العربية هي الافتراضية»** — اللغات ar/en/hi/bn، مبدّل لغة على كل شاشة.
- نمط تدريجي آمن: كل صفحة تغلّف حاويتها الخاصة بـ dir/lang/font (لا قلب html عام) — الصفحات غير المترجمة تبقى سليمة حتى تصلها موجتها.
- أسماء المنشآت/الخدمات تبقى بيانات المالك (لا تُترجم).

### 2.3 مراحل القرب على شاشة الانتظار (عتبات مؤكَّدة)
- بعيد = 4+ أمامك / يقترب = 2-3 / جاهز = 1 / التالي = 0 / يُخدَم = دورك.
- **عدد الأشخاص أمامك هو الإشارة الأساسية**، والوقت المقدَّر مساعد فقط (بعض المحلات بنمط الرقم فقط).

### 2.4 المواعيد ونافذة السماح (Grace) — اختار المستخدم «الخيار أ»
- أي موعد محجوز يصبح غير قابل للحجز (خانة حصرية تظهر معطّلة)، مع قائمة بالمتاح/غير المتاح.
- نافذة سماح قابلة للضبط لكل منشأة (افتراضي 15 دقيقة) تحمي الموعد: walk-in مسح **قبل** فتح النافذة يحتفظ بأولويته، ومسح **بعدها** لا يتجاوز الموعد. والموعد المستقبلي لا يُنادى قبل نافذته.

### 2.5 الاهتزاز مع الصوت
- نغمة تنبيه الدور مصحوبة باهتزاز (`navigator.vibrate`).

### 2.6 الإعلانات وصلاحيات البث الذاتي
- المؤسس يبثّ إعلاناته على كل المحلات أو مجموعة مختارة أو محل واحد، مع وسائط (صورة/فيديو).
- المؤسس يمنح منشأةً صلاحية بثّ إعلاناتها الخاصة، **مقيَّدة بصرامة بصفحات تلك المنشأة فقط**.
- **أولوية المؤسس مطلقة:** إعلان المؤسس يسبق إعلان المحل دائماً.

## 3. قرارات التحصيل/الاشتراك (عبر AskUserQuestion)

> طلب المستخدم: «أخلي التطبيق يقفل بعد شهر ويشتغل بالاشتراك فقط؛ إن قلّت الطلبات بالتحويل، وإن كثرت نسوي وسيلة دفع».

| البند | القرار |
|---|---|
| مدة التجربة | **30 يوماً** مجانية |
| نوع الساعة | **متدحرجة لكل منشأة** (من تاريخ تسجيلها، لا تاريخ موحَّد) |
| أثر القفل | **إيقاف الحجز** للزبون + **شاشة تجديد** للمدير (الدخول يعمل، العمليات مقفلة) |
| الدفع الآن | **تحويل بنكي يدوي** + تفعيل يدوي من المؤسس (طلبات قليلة) |
| الدفع لاحقاً | بوابة (Moyasar/Tap) عبر webhook تضبط **نفس** حقل `paidUntil` (طلبات كثيرة) — بلا إعادة بناء |

- استراتيجية تمهيدية متفق عليها: **شهر تجربة ميدانية مجاني (جمع بيانات) قبل التحصيل**.
- مصدر حقيقة واحد: `trialEndsAt` + `paidUntil` يخدمان التفعيل اليدوي والدفع الإلكتروني مستقبلاً.

## 5. قرارات معمارية تقنية

- **Prisma 6 مثبّت** (Prisma 7 فيه تغييرات config كاسرة).
- جدول `events` **بلا FKs عمداً** (يبقى بعد حذف منشأة/تذكرة) — append-only للقياس.
- ترتيب الطابور عبر `queueSortKeyMs` موحَّد (walk-in=created_at؛ موعد=scheduled_at−graceMs).
- SQL يستخدم `(NOW() AT TIME ZONE 'UTC')` + make_interval لتجنّب علّة timestamp-without-tz مقابل timestamptz.
- المدير يُحتسب مزوّد خدمة في كل المسارات المواجهة للزبون (`role: {in:[manager,barber]}`).
- النشر على Vercel يتطلب `@prisma/adapter-pg` (محرّك Prisma المدمج يفشل serverless).
- ترتيب الميزات المتّفق عليه سابقاً (منجَز): Web Push → شاشة العرض `/display` → التقييم → صفحة الهبوط، ثم i18n الشامل، ثم الاشتراك.
