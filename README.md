# صالون (Salon) — نظام إدارة طوابير عبر QR

نظام SaaS لإدارة طوابير محلات الحلاقة وصالونات التجميل والطوابير العامة (مطاعم/عيادات) عبر رمز QR — **بدون أي تطبيق على الزبون**، فقط متصفّح الجوال.

## رحلة الزبون
`مسح QR` ➔ `صفحة الحجز مباشرة` ➔ `اختيار الخدمة` ➔ `تذكرة بعدّاد حيّ`

## الميزات
- **ثلاثة أنواع منشآت** بثيم لكلٍّ: حلاق رجالي (داكن/ذهبي)، صالون نسائي (وردي/موف)، طابور عام (تركوازي).
- **حجز موحّد أو باختيار موظف** — يتحكم فيه المدير لكل محل.
- **عدّاد حيّ تنازلي** للوقت المتبقي:
  - *تلقائي*: من مجموع مدد الخدمات (مصفوفة زمن لكل حلاق × خدمة).
  - *يدوي*: يُطلقه المدير عند اقتراب انصراف زبون (للمطاعم/الزحمة) مع **تنبيه صوتي قوي + اهتزاز**.
- **تنبيه صوتي متصاعد** كل 5 دقائق + نغمة "حان دورك" (Web Audio، بلا ملفات).
- **استرجاع الحجز** بثلاث طرق: كوكي تلقائي، رابط التذكرة، أو البحث بالاسم/الهاتف.
- **مرونة الاتصال**: إعادة مزامنة تلقائية مع قاعدة البيانات عند عودة الشبكة.
- **توليد QR** بصيغة SVG عالية الدقة + ملصق للطباعة + مشاركة واتساب.
- ترقيم تذاكر **آمن ضد التزامن** (يومي لكل محل).

## المكدّس التقني
- **Next.js 16** (App Router, TypeScript) + **Tailwind v4**
- **PostgreSQL** + **Prisma 6**
- تحديث حي عبر polling + إعادة مزامنة (WebSocket/SSE لاحقاً)

## التشغيل محلياً
```bash
npm install
# اضبط DATABASE_URL و APP_URL في .env
npx prisma migrate dev
node prisma/seed.mjs           # محلات تجريبية (حلاق + صالون)
node prisma/seed-services.mjs  # الخدمات وأزمنة الحلاقين
node prisma/seed-general.mjs   # محل طابور عام (مطعم)
npm run dev
```
ثم افتح `/j/barber-elite` أو `/j/bareeq-salon` أو `/j/restaurant-demo`.

## ملاحظة للإنتاج
اضبط `NEXT_PUBLIC_APP_URL` على الدومين الحقيقي ليعمل الـ QR على جوالات الزبائن (لا localhost).
